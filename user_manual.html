1. 项目简介 / Overview

YZF Sudoku 是一个面向逻辑解题、技巧研究和训练的 Web/WASM 数独工具。它不仅给出答案，还会保留当前盘面、候选状态、步骤结论、链路、高亮和完整解题路径。

主要功能包括：

  • 普通题串、Library、Sukaku、候选盘、Sudoku Coach JSON 与 SCv7_32 导入。
  • 浏览器本地图片识别、原图对照校正、提示数/出数/候选数角色编辑。
  • 题目生成、指定技巧训练生成、ER/EP/ED 与 YZF 评分。
  • 提示一步、应用提示、自动解题路径、所有可选步骤、路径替换与动态解释。
  • 技巧预设、逐项启停、Whip/gWhip 内存模式、Whip/gWhip 最短长度比较、复杂技巧专属子选项。
  • 手工上色、画圈、删数、画链、区块标记、盘面截图与手机分享。
  • 批量出题、批量解题，以及 TLG Truth-Link 集合逻辑编辑器。
  • 专门的手机做题模式，支持竖屏、横屏和触摸标记。

YZF Sudoku is a Web/WASM tool for logical solving, technique research, and training. It preserves the board, candidate state, conclusions, chains, highlights, and full solve path instead of merely returning a solution.

Major features include:

  • Import of plain puzzles, Library strings, Sukaku, candidate grids, Sudoku Coach JSON, and SCv7_32 strings.
  • Local browser OCR with side-by-side review and editable given/solved/candidate roles.
  • Puzzle generation, technique-targeted training generation, and ER/EP/ED/YZF rating.
  • Single hints, hint application, auto-solve paths, available-step search, path replacement, and dynamic explanations.
  • Technique presets, individual toggles, Whip/gWhip memory modes, shortest-length comparison, and advanced sub-options.
  • Manual coloring, circles, eliminations, chains, block marks, board capture, and mobile sharing.
  • Batch generation, batch solving, and the TLG Truth-Link set-logic editor.
  • A dedicated portrait/landscape mobile solve mode with touch-friendly marking.

2. 启动方式 / How to Start

普通 Web 版

普通版应通过 HTTP/HTTPS 打开。例如在 web-app 目录运行：

python -m http.server 8000

然后访问 http://127.0.0.1:8000/index.html。直接双击普通版 index.html 可能导致 WASM、Worker 或 OCR 资源被浏览器拦截。

Standalone 版

Standalone 单文件版可直接双击运行，WASM、OCR runtime 和模型应已经内联。

剪贴板读写、图片复制、系统分享、相机和文件保存能力取决于浏览器权限与安全上下文。通过 HTTPS 或 localhost 打开时兼容性最好。

Regular Web Build

Serve the regular build over HTTP/HTTPS. From the web-app directory, for example:

python -m http.server 8000

Then open http://127.0.0.1:8000/index.html. Double-clicking the regular index.html may cause the browser to block WASM, workers, or OCR assets.

Standalone Build

The single-file Standalone build can be opened directly. WASM, the OCR runtime, and models should already be embedded.

Clipboard access, image copy, system sharing, camera access, and file saving depend on browser permissions and a secure context. HTTPS or localhost gives the best compatibility.

4. 题面输入与现场恢复 / Puzzle Input & Session Restore

支持的输入

  • 81 字符题串：1–9 为提示数，0 或 . 为空格。
  • Library 冒号格式：可保存当前候选删除状态和用户出数。
  • Sukaku / 候选盘：729 字符 Sukaku，或 81 个候选单元格文本。
  • Sudoku Coach：JSON 或 SCv7_32_ 压缩串，支持提示数、出数和候选 mask。

加载流程

  1. 展开“更多：题面输入与导出评分”。
  2. 把内容放入文本框，然后点击“加载”。
  3. 勾选“剪贴板优先”时，加载按钮会先尝试读取剪贴板文本；读取或导入失败后才使用文本框。

电脑浏览器拒绝剪贴板权限时，可取消“剪贴板优先”后直接加载文本框。手机做题模式中的“题面输入”会返回分析界面并自动展开输入面板。

自动保存现场

程序会在本机浏览器保存当前盘面、候选状态、语言和技巧配置，下次打开时自动恢复。“清除本地保存”会删除下次恢复所用的盘面、语言和技巧配置，但不会清空当前盘面。

手工标记、当前提示预览、解题路径预览和 TLG 临时逻辑不会作为主现场保存。重要结构请截图或导出。

Coach 候选数 mask

userCellCandidates 由 81 个十进制 mask 组成，用 - 分隔。数字 d 对应 1 << d；例如候选 2、3、6 的 mask 为 4 + 8 + 64 = 76。

Supported Inputs

  • 81-character puzzle: 1–9 are givens; 0 or . is empty.
  • Library colon format: preserves current candidate eliminations and user digits.
  • Sukaku / candidate grid: a 729-character Sukaku string or 81 candidate-cell tokens.
  • Sudoku Coach: JSON or an SCv7_32_ compressed string with givens, user digits, and candidate masks.

Loading

  1. Open “More: Puzzle Input / Export / Rating”.
  2. Put the input in the text area and press Load.
  3. When Prefer Clipboard is checked, Load first tries clipboard text and falls back to the text area if reading or import fails.

If desktop clipboard permission is denied, disable Prefer Clipboard and load the text area directly. Puzzle Input inside mobile solve mode returns to the analysis view and opens the input panel.

Automatic Session Restore

The browser locally saves the current board, candidate state, language, and technique configuration, then restores them on the next visit. Clear Saved Session removes the board, language, and technique data used for the next restore, but does not clear the current board.

Manual marks, the current hint preview, solve-path previews, and temporary TLG logic are not part of the main saved session. Capture or export important structures.

Coach Candidate Masks

userCellCandidates contains 81 decimal masks separated by -. Digit d corresponds to 1 << d; candidates 2, 3, and 6 therefore use 4 + 8 + 64 = 76.

5. 图片识别与对照校正 / OCR & Review

图片识别完全在浏览器本地运行，不上传图片，也不使用在线 fallback。模型按需加载；首次使用可能下载较大的运行库与模型，后续会使用本地缓存。下载中断时，支持的服务器和浏览器会尝试断点续传。

识别入口

  • 选择图片识别：电脑选择文件，手机可从相册选择。
  • 拍照识别：手机请求后置相机；部分浏览器会弹出“相机/相册”选择器。
  • 从剪贴板识别：电脑读取剪贴板中的图片。
  • Ctrl+V：焦点不在输入框时，可直接粘贴截图。

OCR 对照校正窗口

  • 左侧显示识别后的盘面图片，中间显示固定 9×9 校正盘面；点击任一侧会同步选中同一格。
  • 右侧可切换提示数、出数、候选数。提示数显示为黑色大数字，出数显示为蓝色大数字。
  • 提示数/出数模式中，数字会替换当前格；再次输入相同数字会清空。候选模式中，数字用于切换候选。
  • “上一格/下一格”移动选格；“清空”清除当前格；“撤销/重做”处理本次校正历史；“恢复识别结果”回到模型最初输出。
  • “确认并导入”把校正结果作为可编辑 OCR 草稿导入；“取消”放弃本次识别。

电脑与手机

电脑和横屏空间充足时使用三栏对照，并提供“全屏校正”。窄屏手机会纵向排列图片、盘面和控制区；窄屏下全屏按钮可能隐藏。进入 OCR 校正时会退出手机做题模式，避免横屏全屏误进入做题布局。

电脑键盘可使用 1–9、0/Delete/Backspace、方向键、Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 和 Esc。

导入后的继续校正

确认导入后，若仍有错误，可在主盘面继续编辑。OCR 草稿的数字盘会显示“提示数/出数”角色按钮；选择角色后输入大数字，可继续修正黑色提示数和蓝色出数身份。

OCR 只使用黑色提示数检查唯一解。检查失败不会拒绝导入，而是保留草稿供人工修正；唯一性尚未确认时，不应依赖 UR、AUR 等唯一性技巧。

OCR runs entirely in the browser: images are not uploaded and no online fallback is used. Models load on demand; the first run may download sizable runtime/model assets, while later runs use local cache. Interrupted downloads attempt to resume when supported.

OCR Entries

  • Select Image: choose a file on desktop or a photo from the mobile library.
  • Take Photo: requests the rear camera; some browsers show a camera/gallery chooser.
  • Read Clipboard: reads an image from the desktop clipboard.
  • Ctrl+V: paste a screenshot when focus is not inside an editable field.

OCR Review Window

  • The recognized image is shown on the left and a fixed 9×9 correction grid in the middle. Clicking either side selects the same cell.
  • Switch among Given, Solved Digit, and Candidates. Givens are black large digits; solved digits are blue.
  • In Given/Solved mode, a number replaces the cell; pressing the same number clears it. Candidate mode toggles pencil marks.
  • Previous/Next moves selection; Clear removes the cell; Undo/Redo edits correction history; Reset OCR Result restores the original model output.
  • Confirm & Import imports an editable OCR draft; Cancel discards the recognition.

Desktop and Mobile

Desktop and roomy landscape layouts use three columns and provide Fullscreen Review. Narrow phones stack the image, board, and controls vertically; the fullscreen button may be hidden. Opening OCR review exits mobile solve mode so landscape fullscreen remains in the correction editor.

Desktop keyboard controls include 1–9, 0/Delete/Backspace, arrow keys, Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, and Esc.

Further Correction After Import

After confirmation, continue editing on the main board if necessary. An OCR draft adds a Given/Solved role button to the number pad so black givens and blue solved digits can still be corrected.

Only black givens are used for the uniqueness check. Failure does not reject the draft. Do not rely on uniqueness techniques such as UR/AUR until uniqueness has been confirmed.

6. 盘面编辑 / Board Editing

  1. 在数字盘选择 1–9。
  2. 选择“出数”或“候选”模式。
  3. 点击/触摸目标格：出数模式设置大数字；候选模式切换当前候选。
  • 再次输入当前大数字可清除该出数；原始提示数不可直接覆盖。
  • “撤销/重做”作用于盘面编辑和应用提示产生的历史。
  • 点击“提示一步”只预览逻辑，不修改盘面；必须点击“应用提示”才写入盘面。
  • OCR 草稿允许在唯一解尚未成立时继续修改，避免 engine 的严格导入阻断校正。

触屏提示：普通编辑与手工标记都采用“先选数字或格子，再点目标”的大按钮流程，避免依赖候选小字的精确点击。

  1. Select 1–9 on the number pad.
  2. Choose Value or Candidate mode.
  3. Click/tap the target cell: Value sets a large digit; Candidate toggles the selected pencil mark.
  • Entering the same large digit again clears it; original givens cannot be overwritten directly.
  • Undo/Redo covers board edits and applied hints.
  • Hint previews logic without changing the board; Apply Hint commits it.
  • OCR drafts remain editable even before the givens form a unique puzzle.

Touch note: normal editing and manual marks use large-button “select digit/cell, then target” flows instead of requiring precise taps on tiny candidate text.

7. 生成、训练与评分 / Generate, Train & Rate

普通生成

先选择 ER 难度分档，再点击“生成”。可选 Random、Easy、Medium、Hard、Unfair、Extreme 和 Insane。状态栏会显示提示数数量和评分。

训练生成

在“训练”下拉框选择一个技巧，再点击“训练生成”。程序会反复生成并完整解题，直到找到解题路径中包含该技巧的题目。复杂技巧可能需要较长搜索；运行期间按钮会锁定并显示已用时间。

评分当前题目

“评分当前题目”会优先识别文本框或当前盘面的格式。普通题使用 puzzle 评分；含候选状态的 Library/Sukaku/Coach 输入使用候选盘评分。结果通常包含 ER、EP、ED，并可能显示 YZFRate。

训练生成使用当前启用的技巧配置。为了得到可复现结果，先在“技巧”页签选好预设和子选项。

Normal Generation

Select an ER difficulty band, then press Generate. Available bands are Random, Easy, Medium, Hard, Unfair, Extreme, and Insane. The status reports clue count and rating.

Training Generation

Select a technique in the Training list, then press Training Generate. The program repeatedly generates and solves puzzles until the solve path contains that technique. Advanced targets may take substantially longer; elapsed time is shown while the action is locked.

Rate Current Puzzle

Rate Current Puzzle detects the text-area or current-board format. Plain puzzles use puzzle rating, while Library/Sukaku/Coach inputs with candidate state use candidate-grid rating. Results normally include ER, EP, ED, and may include YZFRate.

Training generation uses the currently enabled technique configuration. Choose the desired preset and sub-options first for reproducible results.

8. 提示、应用与自动解题 / Hint, Apply & Auto Solve

  • 提示一步：按当前技巧开关和顺序寻找下一步，显示结论、高亮与链路，但不修改盘面。
  • 应用提示：把当前提示的出数/删数写入盘面，并进入撤销历史。
  • 解释：当前提示或选中的路径步骤可解释时，顶部“解释”按钮会启用，打开“为什么这一步成立”的动态教程。
  • 自动解题：计算从当前盘面开始的完整逻辑路径，并打开“解题路径”页签。它主要用于查看和比较路径，不会把所有步骤一次性永久写入当前编辑盘面。

耗时搜索在普通 Web 版优先放入 Worker，保持界面可操作；Standalone 或不支持 Worker 的浏览器会回退到主线程。

状态可能显示 solved、NoResult、Invalid 或步数上限等。找不到高级技巧时，先确认技巧已启用，并检查当前题目/候选状态是否合法。

  • Hint: finds the next step under the current technique order, showing conclusions, highlights, and chains without changing the board.
  • Apply Hint: commits the current placement/elimination and adds it to undo history.
  • Explain: when the current hint or selected path step is explainable, the top Explain button opens a dynamic “why this works” tutorial.
  • Auto Solve: computes a full logical path from the current board and opens the Solve Path tab. It is primarily a path viewer and does not permanently apply every step to the editable board at once.

Long tasks use a Worker in the regular Web build when available. Standalone or unsupported browsers fall back to the main thread.

Status may report solved, NoResult, Invalid, or a step limit. If an advanced technique is missing, verify that it is enabled and that the puzzle/candidate state is valid.

9. 解题路径与可选步骤 / Path & Available Steps

解题路径

  • 点击某一步，会把盘面预览到该步执行前，并显示该步高亮；展开节点可查看描述、nodes、edges、rank 和 hash。
  • Force Chain 等多分支提示会显示分支切换控件。电脑还可使用 ←/→ 或 [/] 切换分支。
  • 路径替换后，顶部会显示旧/新步数、评分变化和“撤销分支”入口。

所有步骤 / 可选步骤

“所有步骤”在当前盘面收集多个合法步骤。可使用：

  • 关键词过滤技巧名、删数、格坐标或描述。
  • 按技巧过滤。
  • 默认排序，或按“出数/删数优先”排序。
  • “可替换”只显示可绑定到当前解题路径某一步的候选。
  • 点击“清除”会同时重置关键词、技巧、排序和“可替换”筛选。

预览与替换

单击/轻触步骤只预览。若步骤标有“可替换”，电脑右键、手机长按约 0.65 秒，会用该步骤替换原路径对应步骤，并从替换点继续重算。与原步骤相同的候选不会替换。

路径和可选步骤中的盘面是预览状态。导出或保存现场前，应返回实际编辑盘面，或明确使用替换后的路径结果。

Solve Path

  • Click a step to preview the board immediately before it and display its highlights. Expand nodes to inspect the description, nodes, edges, rank, and hashes.
  • Multi-branch hints such as Force Chains expose branch controls. Desktop also supports ←/→ or [/].
  • After path replacement, a panel shows old/new step counts, rating deltas, and an Undo Branch action.

All / Available Steps

All Steps collects multiple legal options for the current board. You can:

  • filter by technique name, conclusion, coordinate, or description;
  • filter by technique;
  • use default order or sort placements/eliminations first;
  • show only Replaceable options that can bind to the current solve path;
  • press Clear to reset the text, technique, sort, and Replaceable filters together.

Preview and Replace

A normal click/tap only previews. For a Replaceable item, right-click on desktop or long-press for about 0.65 seconds on touch to replace the corresponding original step and recompute the remainder. An option identical to the current step is not replaced.

Boards shown in Path and Available Steps are previews. Before exporting or relying on session restore, return to the live editable board or intentionally use the replaced path result.

10. 技巧配置与高亮 / Technique Settings & Highlights

预设按钮

  • All In：启用全部已实现技巧。
  • High Speed：关闭一批耗时最大的高级技巧，兼顾覆盖率。
  • Extreme Speed：进一步关闭较慢技巧，优先速度。
  • Whip Rating：基础技巧 + Whip/gWhip，并自动使用大内存评分配置；默认返回最短 Whip，可通过下方选项把 gWhip 纳入长度比较。
  • Braid Rating：基础技巧 + Braid/gBraid。

逐项配置

技巧表可逐项启用/关闭，并显示分数与难度颜色。Complex AIC 可单独勾选 with AMSLS，JE 可勾选 with JEPOM。

Whip/gWhip 搜索内存模式：

  • 自动：普通求解使用常规队列，Whip Rating 使用大内存。
  • 普通：速度和内存优先。
  • 大内存：提高搜索覆盖率，但更耗内存。

gWhip 参与最短长度比较：仅在 Whip 与 gWhip 同时启用时生效。程序先取得最短 Whip，再只搜索可能更短的 gWhip；gWhip 严格更短时返回 gWhip，同长度仍优先 Whip。

技巧配置会随主现场自动保存。预设会重置 Complex AIC/JE 的专属子选项，使用后请重新确认。

高亮阅读

一般高亮包括出数、删数、结构格、强/弱链、ON/OFF 节点、ALS/AF 区域、guardian 和分支。点击顶部“技巧说明”打开 techniques.html，查看每个技巧的玩家向解释。

Guardian Force Chain

Dead pattern 的 guardian 不可能全部为假，因此至少一个为真。如果每个 guardian 为真都推出同一个结论，该结论成立。UR Guardian FC 与 Triplet Oddagon/Tridagon Guardian FC 使用相同的强制链原则，只是 deadly pattern 不同。

Preset Buttons

  • All In: enables every implemented technique.
  • High Speed: disables a group of the most expensive techniques while retaining broad coverage.
  • Extreme Speed: disables more slow techniques and prioritizes speed.
  • Whip Rating: basic techniques plus Whip/gWhip with the large-memory rating configuration. It returns the shortest Whip by default; the option below adds gWhip to the length comparison.
  • Braid Rating: basic techniques plus Braid/gBraid.

Individual Settings

The technique table allows individual toggles and shows score/difficulty coloring. Complex AIC has a with AMSLS sub-option; JE has with JEPOM.

Whip/gWhip search memory modes:

  • Auto: normal queues for solving, large memory for Whip Rating.
  • Normal: prioritizes speed and memory use.
  • Large: improves search coverage at higher memory cost.

Compare shortest length with gWhip: applies only when both Whip and gWhip are enabled. The solver finds the shortest Whip first, then searches only for a strictly shorter gWhip. Whip wins ties.

Technique settings are saved with the main session. Presets reset the Complex AIC/JE sub-options, so re-check them afterward.

Reading Highlights

Highlights may include placements, eliminations, structure cells, strong/weak links, ON/OFF nodes, ALS/AF regions, guardians, and branches. Open the top Technique Guide link for player-facing explanations in techniques.html.

Guardian Force Chain

Guardians of a dead pattern cannot all be false, so at least one is true. If every possible true guardian produces the same conclusion, that conclusion is valid. UR and Triplet Oddagon/Tridagon Guardian FC use the same forcing principle with different deadly patterns.

  • 候选类模式：左键候选执行添加；右键候选执行次要动作。除画链外，次要动作通常是删除该模式标记。

  • 不要依赖直接点小候选：先点格子，再点大数字盘中的数字。
  • 使用“添加/清除”明确选择动作。候选类标记会自动确保候选数可见。
  • 做题模式中点击“标记”。竖屏空间足够时面板内嵌在盘面下方；横屏或高度不足时放入右侧/底部抽屉。

  • 撤销线：删除最后一条手动画链。
  • 取消起点：取消尚未完成的链起点。
  • 完成区块：把当前选中的候选集合固定成一个区块。
  • 撤销区块：先撤销草稿最后一个节点；没有草稿时撤销最后一个已完成区块。
  • 清空标记：清除全部手工颜色、圈、删数、线和区块。

应用删数与截图

“应用全部删数”只应用“正式删数”，不会应用“预备删数”。勾选“清除简单步骤”后，还会连续应用 Full House、Hidden/Naked Single、Locked Candidates、Pair、Triple 和 Quad，直到遇到更高级步骤。

“截图”按屏幕当前显示生成盘面 PNG，包含全部手工标记。电脑优先复制到图片剪贴板；手机优先打开系统分享；能力不可用时自动下载。

启用 TLG 编辑时，普通技巧高亮、链路和手工标记只会暂时隐藏；关闭 TLG 后恢复。手工标记不会随主现场自动保存。

12. 批量任务 / Batch Tasks

批量出题

  1. 选择“批量出题”、输出文件名和主界面的难度。
  2. 若“训练”下拉框选择了技巧，批量任务会只输出包含该技巧的训练题；未选择则普通批量生成。
  3. 点击“开始”持续生成，点击“停止”结束并关闭/下载文件。

每行是制表符分隔记录，包含序号、技巧、题串、答案、难度、尝试次数、提示数和评分字段。

批量解题

  1. 选择“批量解题”。
  2. 选择纯文本输入文件，一行一题；空行和以 # 开头的行会忽略。
  3. 点击“开始”，输出每题的状态、步数、YZF 评分、最难技巧和错误信息。

文件与平台差异

支持 File System Access API 的桌面浏览器会先让你选择保存位置，并在运行中持续追加；其它浏览器（常见于手机和部分 Firefox/Safari）会在任务结束或停止时生成下载文件。

批量出题默认持续运行，必须点击“停止”。关闭页面前先停止，否则尚未下载的内存结果可能丢失。

Batch Generation

  1. Select Batch Generate, an output filename, and the main difficulty.
  2. If a Training technique is selected, only training puzzles containing that technique are emitted; otherwise generation is unrestricted.
  3. Press Start to generate continuously and Stop to finish and close/download the file.

Each tab-separated line contains index, technique, puzzle, solution, difficulty, attempts, clue count, and rating fields.

Batch Solving

  1. Select Batch Solve.
  2. Choose a plain-text input file with one puzzle per line. Blank lines and lines beginning with # are ignored.
  3. Press Start. Output includes status, steps, YZF rating, hardest technique, and errors.

Files and Platform Differences

Desktop browsers with the File System Access API ask for a destination and append while running. Other browsers, commonly mobile and some Firefox/Safari versions, create a download when the task finishes or is stopped.

Batch generation runs continuously by default and must be stopped. Stop before closing the page or in-memory output that has not yet downloaded may be lost.

13. TLG Solver / Truth-Link Logic

TLG Solver 用 Truths、Links、Virtual Set、定式 AUR 和 DAUR/DUR 描述集合逻辑，并搜索这些约束共同推出的删数或出数。只有勾选“启用 TLG 编辑”后，TLG 才会接管盘面点击和专属高亮。

TLG 编辑期间，普通技巧高亮、链路和手工标记只会暂时隐藏；关闭 TLG 编辑后恢复，原数据不会删除。

核心对象

  • Truth：投影中必须恰好覆盖一次的集合，可使用行、列、宫或单元格描述符。
  • Link：投影中最多覆盖一次的集合，也用于判断集合外候选是否可删。
  • Virtual Set：用户直接给出的虚拟约束集合。
  • 定式 AUR：明确指定四格位置与本体数对 {a,b}，限制 maxBodyFootprint ≤ 3。
  • DAUR：用户标记潜在本体候选池，程序动态展开四格 AUR 和六格 2×3 / 3×2 DUR。
  • GUR：用户直接标记一个通用候选云。程序不预设几何构型，而是枚举固定格集合的全部合法局部完成式，按行数、列数、宫数 exact-cover footprint 分组；可安全合并时编译为 k-1，否则保留逐完成式 no-good。
  • 六格 DUR：六格位置与三数组的可交换完成对，限制 maxBodyFootprint ≤ 5。

初始候选与唯一性门控

TLG 分开保存初始候选盘与当前候选盘。Sukaku 只是输入格式，并不自动代表训练盘。

  • 唯一解：核验初始可交换局面（默认）：定式 AUR/DUR 必须在初始候选盘满足交换前提，当前盘至少保留一个 deadly completion。
  • 训练盘：允许初始缺数：用于人为构造的多解/Rank 训练候选盘，只核验当前 deadly completion。

输入流程与参数

  1. 展开 TLG Solver，勾选“启用 TLG 编辑”。
  2. 需要候选盘时，把 Sukaku 或 81 个候选单元格粘贴到题面输入框，选门控后点击“导入 TLG 候选盘面”。
  3. Truths：点击两个共享同一行、列或宫且数字相同的候选；点击空单元格背景可切换 Cell Truth。
  4. Links：选择自动、行/列、宫或单元格，再依次点击两个候选。自动模式下，同一格两个候选优先解释为 Cell Link。
  5. Virtual Set：点击候选切换成员。“应用 Truths 数”表示该 Virtual Set 的基数；当前后端按 1–4 处理，填 0 时按 1。
  6. AUR：先在“AUR 分组”选择 AUR 1 或 AUR 2，再点击候选，可同时维护两组独立 AUR。
  7. DAUR：点击候选建立动态 AUR/DUR 候选池。
  8. GUR：点击候选建立通用候选云；至少覆盖四个单元格。该模式只负责动态验真，不替代现有 AUR/DAUR 静态与模板搜索。
  9. 点击“查找删数”。有效结果可再用“转换冗余 Truths”和“移除未使用 Links”精简。

“当前 TLG 状态”列表中的条目可逐项删除。“清空 TLG 状态”会清除 Truths、Links、Virtual Set、AUR/DAUR、候选盘和计算结果，但不会清空主盘面的题目。

批量选择与右键菜单

电脑按住 Ctrl（macOS 为 Command）点击多个候选，再右键打开菜单，可批量添加/移除行、列、宫、单元格 Truth/Link，或切换 Virtual Set、AUR、DAUR。普通点击会清空先前批选。

手机可逐个使用当前输入模式；长按右键菜单是否出现取决于浏览器。复杂批量编辑建议使用电脑。

高亮图例

  • House 颜色固定为 R 青绿、C 金黄、B 紫色。
  • House Truth：候选外围分色圆环；House Link：候选数字后的分色底色。
  • Cell Truth：单元格内缩蓝框；Cell Link：整格浅蓝底。
  • Virtual Set：紫色实线圈；AUR 1：橙色虚线；AUR 2：蓝色虚线；DAUR：青色点线；GUR：棕色双线圈。
  • 最终删数：红色候选和红叉，始终绘制在最上层。

结果表示

大写 R/C/B/N 表示 Truth，小写 r/c/b/n 表示 Link，N/n 表示单元格集合。状态栏还会显示唯一性门控、候选数规模和 DAUR 展开数量。

TLG Solver describes set logic using Truths, Links, a Virtual Set, fixed AURs, and DAUR/DUR constraints, then searches for implied eliminations or assignments. It takes over board input only while Enable TLG Editing is checked.

Ordinary highlights, chain overlays, and manual marks are hidden rather than deleted during TLG editing.

Core Objects

  • Truth: a set covered exactly once, described by row, column, box, or cell.
  • Link: a set covered at most once and used for external-candidate elimination.
  • Virtual Set: a user-supplied virtual constraint.
  • Fixed AUR: an explicit four-cell position and body pair {a,b}, with maxBodyFootprint ≤ 3.
  • DAUR: a user-marked body-candidate pool dynamically expanded into four-cell AURs and six-cell 2×3 / 3×2 DURs.
  • GUR: a template-free candidate cloud. The engine enumerates legal local completions over the fixed cell set and groups them by row-digit, column-digit, and box-digit exact-cover footprint. It emits a safe k-1 guard when closure is proven; otherwise it keeps exact per-completion no-goods.
  • Six-cell DUR: a six-cell swappable completion for a three-digit set, with maxBodyFootprint ≤ 5.

Initial Candidates and Uniqueness Gate

TLG stores the initial candidate grid separately from the current candidate grid. Sukaku is only an input format and does not automatically mean training mode.

  • Unique puzzle: verify initial swap pair (default): fixed AUR/DUR constraints must satisfy the swap premise in the initial grid, and the current grid must retain a deadly completion.
  • Training grid: allow missing initial candidates: for deliberately constructed multi-solution/Rank grids; only the current deadly completion is checked.

Input Workflow and Parameters

  1. Open TLG Solver and enable TLG editing.
  2. For a candidate grid, paste Sukaku or 81 candidate-cell tokens into the puzzle input, choose the gate, then press Import TLG Candidate Grid.
  3. Truths: click two same-digit candidates sharing a row, column, or box. Click empty cell background to toggle a Cell Truth.
  4. Links: choose Auto, Row/Column, Box, or Cell, then click two candidates. Auto prioritizes a Cell Link for two candidates in one cell.
  5. Virtual Set: click candidates to toggle membership. Truths to Apply is the Virtual Set cardinality; the current backend uses 1–4 and treats 0 as 1.
  6. AUR: choose AUR 1 or AUR 2 in AUR Group before clicking candidates; two independent groups can be maintained.
  7. DAUR: click candidates to build the dynamic AUR/DUR candidate pool.
  8. GUR: click candidates to build a generic cloud spanning at least four cells. GUR performs dynamic validation and does not replace the existing fixed AUR/DAUR paths.
  9. Press Find Eliminations. Use Convert Redundant Truths and Remove Unused Links after a valid result.

Items in Current TLG State can be removed individually. Clear TLG State removes Truths, Links, the Virtual Set, AUR/DAUR groups, the candidate grid, and computed results without clearing the puzzle on the main board.

Batch Selection and Context Menu

On desktop, hold Ctrl (Command on macOS), click candidates, then right-click to batch add/remove row, column, box, or cell Truth/Link descriptors, or toggle Virtual Set, AUR, and DAUR membership. A normal click clears the previous multi-selection.

Mobile can edit one candidate at a time through the selected mode. Long-press context-menu behavior depends on the browser; desktop is recommended for complex batch editing.

Highlight Legend

  • House colors are fixed: R teal, C amber, B violet.
  • House Truth: segmented outer ring; House Link: segmented background behind the digit.
  • Cell Truth: inset blue border; Cell Link: light-blue cell fill.
  • Virtual Set: solid violet ring; AUR 1: orange dashed; AUR 2: blue dashed; DAUR: cyan dotted; GUR: brown double ring.
  • Final eliminations: red candidate and red cross on the top layer.

Result Notation

Uppercase R/C/B/N denotes Truths; lowercase r/c/b/n denotes Links; N/n is a cell set. Status also reports the uniqueness gate, candidate count, and DAUR expansion count.

14. 内置超难题库 / Built-in Superhard Bank

Insane/超难生成可使用压缩内置题库随机抽取题目，解压后导入当前盘面。轻量压缩 bank 比直接保存 81 字符题串明显更小，并适合 WASM/Standalone 打包。

  • 普通题串：约 81 字节/题。
  • Puzzle19 raw：约 19 字节/题。
  • 压缩 bank：实际大小取决于题库分布，通常更小。

Insane/superhard generation can draw randomly from the compressed built-in bank and import the decoded puzzle. The packed bank is much smaller than storing raw 81-character strings and is suitable for WASM/Standalone builds.

  • Raw puzzle string: about 81 bytes per puzzle.
  • Puzzle19 raw: about 19 bytes per puzzle.
  • Compressed bank: actual size depends on the puzzle distribution and is normally smaller.

15. 导出、截图与分享 / Export, Capture & Share

题串导出格式

  • 原始题串：只导出最初提示数。
  • 已知数字串：导出当前所有大数字。
  • 候选数字串：按单元格输出当前候选文本。
  • Sukaku 字串：729 字符候选盘。
  • Library 题串：保存题面、出数和候选删除状态，最适合复现当前局面。
  • To Coach：导出 SCv7_32 Coach 压缩串。

点击“导出题串”后，结果写回输入框，并在浏览器允许时复制到文本剪贴板。所选导出格式会保存在本机。

截图与分享

需要保留链路、圈、颜色和区块时，请使用“手工标记”里的“截图”，而不是题串导出。电脑优先复制 PNG；手机优先系统分享。

Library/Coach/Sukaku 适合保存候选状态；普通 81 字符串无法保存手工删候选、链路和标记。

Puzzle Export Formats

  • Original Puzzle: original givens only.
  • Known Digits: all current large digits.
  • Candidate Text: current candidate text by cell.
  • Sukaku: the 729-character candidate grid.
  • Library: board, solved digits, and candidate eliminations; best for reproducing the current state.
  • To Coach: an SCv7_32 Coach compressed string.

Capture and Share

To preserve chains, circles, colors, and blocks, use Capture in Manual Marks rather than puzzle export. Desktop prioritizes PNG clipboard copy; mobile prioritizes system share.

Library/Coach/Sukaku preserve candidate state. A plain 81-character string cannot preserve manual candidate deletions, chains, or marks.

16. 手机做题模式 / Mobile Solve Mode

宽度不超过约 900px 或使用粗指针/触屏时，顶部会出现“做题”。进入后，真实盘面和数字盘会移动到固定视口布局，不是复制一个新盘面，因此编辑、撤销和提示与分析界面保持同步。

顶部与底部按钮

  • 返回：退出做题模式并回到原滚动位置。
  • 新题：选择 ER 难度后生成；已有作答或标记时会警告，确认后清除进度和手工标记。
  • 清除：清除当前选中格的大数字；候选模式下可清除当前选中的候选。
  • 撤销/重做：与主界面共用历史。
  • 标记：打开完整手工标记面板。
  • 更多：打开提示、应用、可选步骤、题面输入、候选显示、同数字高亮、全屏、分析模式和语言。

更多功能

  • 提示一步 / 应用提示：与主界面相同。
  • 可选步骤：退出做题布局后打开“可选步骤”页签。
  • 题面输入：退出做题布局后展开输入面板并聚焦文本框。
  • 隐藏/显示候选数：只改变做题界面的显示，不删除候选；候选标记模式会自动重新显示候选。
  • 关闭/开启同数字高亮：根据数字盘当前数字，高亮盘面上相同的大数字。
  • 全屏：调用浏览器 Fullscreen API。
  • 分析模式：退出专用做题界面，返回完整分析 UI。

候选显示和同数字高亮偏好会保存在本机。横屏时盘面在左、控制区在右；竖屏时纵向排列并根据可用高度自动缩放。进入普通全屏时，小屏/触屏设备可能自动切入做题模式；OCR 校正全屏除外。

手机图片与缓存

手机没有等同于电脑 Ctrl+V 的稳定入口，请使用“选择图片识别”或“拍照识别”。Chrome Android 没有完全等同于 Ctrl+F5 的快捷键；开发测试可使用带版本号的 URL，或清除该站点缓存。

At widths up to about 900px or with a coarse/touch pointer, the top bar shows Solve. Entering it moves the real board and number pad into a fixed viewport shell rather than cloning them, so edits, undo, and hints stay synchronized with analysis mode.

Top and Bottom Actions

  • Back: exits solve mode and restores the previous scroll position.
  • New Puzzle: choose an ER band and generate. Existing progress or marks trigger a warning; confirmation clears progress and manual marks.
  • Clear: clears the selected large digit, or the selected candidate in Candidate mode.
  • Undo/Redo: shares history with the main interface.
  • Marks: opens the full Manual Marks panel.
  • More: opens Hint, Apply, Available Steps, Puzzle Input, candidate visibility, same-digit highlighting, Fullscreen, Analysis Mode, and language.

More Functions

  • Hint / Apply Hint: same behavior as the main interface.
  • Available Steps: leaves the solve layout and opens the Available Steps tab.
  • Puzzle Input: leaves solve mode, opens the input panel, and focuses the text area.
  • Hide/Show Candidates: display-only; candidates are not deleted. Candidate mark modes automatically show them again.
  • Disable/Enable Same-Digit Highlight: highlights large digits matching the current number-pad digit.
  • Fullscreen: calls the browser Fullscreen API.
  • Analysis Mode: exits the dedicated solve interface.

Candidate visibility and same-digit preferences are stored locally. Landscape places the board on the left and controls on the right; portrait stacks them and scales to available height. On small/touch devices, normal fullscreen may automatically enter solve mode; OCR correction fullscreen is exempt.

Mobile Images and Cache

Mobile has no reliable equivalent of desktop Ctrl+V; use Select Image or Take Photo. Chrome Android has no exact Ctrl+F5; for development use versioned URLs or clear the site's cache.

17. Standalone 版本 / Standalone Version

Standalone 版用于离线运行，不需要本地服务器。构建脚本需要把应用 JS、WASM、OCR JS、ONNX Runtime Web、runtime WASM 和两个模型文件内联或打包进单文件 HTML。

  • 普通 Web 版可使用 Solver/Training/Batch Worker；Standalone 会在 Worker 不可用时回退主线程。
  • 浏览器仍可能限制剪贴板、相机、系统分享和文件选择，这与是否离线无关。
  • 单文件体积较大，首次打开和 OCR 首次初始化可能更慢。

若普通版 OCR 正常而 Standalone 失败，检查 ort.min.js、runtime WASM、puzzle_localizer.ort、puzzle_classifier.ort 是否完整内联，并确认 OCR 模块没有残留动态 import() 或本地 fetch()。

The Standalone build runs offline without a local server. Its build script must embed or package the app JS, WASM, OCR JS, ONNX Runtime Web, runtime WASM, and both model files into one HTML file.

  • The regular Web build can use Solver/Training/Batch Workers; Standalone falls back to the main thread when workers are unavailable.
  • The browser may still restrict clipboard, camera, system share, and file pickers independently of offline operation.
  • The single file is large, so first open and first OCR initialization may be slower.

If OCR works in the regular build but fails in Standalone, verify that ort.min.js, runtime WASM, puzzle_localizer.ort, and puzzle_classifier.ort are fully embedded, and that the OCR module has no remaining dynamic import() or local fetch().

18. 常见问题 / Troubleshooting

问题 / Issue原因 / Cause处理 / Fix
加载总是用了剪贴板里的旧题“剪贴板优先”已勾选。取消勾选，或先更新剪贴板内容。
图片识别提示 no available backend foundORT runtime/WASM 路径错误或 Standalone 内联不完整。普通版检查 OCR runtime 资源；Standalone 重新打包。
OCR 下载反复从头开始服务器不支持 Range、缓存被禁用，或隐私模式清理了本地数据。使用支持 Range 的静态托管，允许站点存储；网络恢复后重试。
OCR 盘面数字身份错误模型把彩色出数识别成提示数，或反之。在对照校正窗口切换“提示数/出数”，或导入后用 OCR 角色按钮继续修改。
OCR 非唯一，无法使用 UR/AUR黑色提示数尚未校正到唯一题面。先在对照盘面修正提示数；唯一性未确认前不要使用唯一性技巧。
手工候选标记在手机上点不中触屏不会直接消费小候选点击。先点格子，再点大数字盘；使用“添加/清除”。
“应用全部删数”没有处理预备删数预备删数设计为纯视觉标记。把需要执行的候选改为“正式删数”。
截图没有复制到剪贴板浏览器不支持图片剪贴板或权限被拒绝。程序会回退下载；手机优先尝试系统分享。
批量任务停止后才出现文件浏览器不支持 File System Access API。这是正常回退行为；停止后保存下载文件。
自动解题后盘面没有直接变成终盘自动解题生成的是可预览的完整路径。在“解题路径”逐步查看；需要改盘面时使用“提示一步 + 应用提示”。
技巧找不到，但 native 测试能找到技巧未启用、候选状态不同，或前端 WASM/缓存不是最新版。检查技巧页、重新加载同一候选盘，并刷新版本缓存。
手机全屏后进入了做题模式小屏/触屏全屏会自动选择专用做题布局。使用“分析模式”返回；OCR 校正全屏不会触发该切换。
TLG 开启后普通标记消失TLG 独占视觉层，普通高亮被临时隐藏。关闭“启用 TLG 编辑”，原标记会恢复。
恢复现场后没有手工标记主现场只保存盘面、语言和技巧配置。重要手工结构请用截图保存。
